# Documents à déposer dans ce répertoire

| Fichier attendu | Où le récupérer | Utilisé dans |
|---|---|---|
| `Microsoft-Copilot-Studio-Licensing-Guide-June-2026-PUB.pdf` | https://cdn-dynmedia-1.microsoft.com/is/content/microsoftcorp/microsoft/bade/documents/products-and-services/en-us/bizapps/Microsoft-Copilot-Studio-Licensing-Guide-June-2026-PUB.pdf | Cas d'usage nº 2, source de connaissances chargée dans l'agent |

Le fichier n'est pas livré avec le lab pour ne pas redistribuer un document Microsoft susceptible d'être mis à jour. Téléchargez la version courante avant la session et déposez-la ici.

Tout autre PDF, document Word ou fichier texte peut le remplacer. Choisissez de préférence un document contenant des informations précises et récentes, absentes des connaissances générales du modèle : c'est ce qui rend la démonstration de l'ancrage convaincante.

Ce répertoire n'est pas référencé fichier par fichier depuis le lab : le Markdown pointe vers le répertoire `Docs/` et vers le lien de téléchargement officiel. Vous pouvez donc y ajouter vos propres documents sans modifier le lab.
